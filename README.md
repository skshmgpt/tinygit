# tinygit

tinygit is a version control system I built after getting intrigued by
[wyag](https://wyag.thb.lt) and then deep-diving into Git internals.


i implemented few git commands like 
- tinygit init ( initialises a new empty repo)
- tinygit add (stages a file for commit)
- tinygit commit
- tinygit cat-file (to print decompressed file contents)
- tinygit branch
- tinygit checkout (this actually matches your working dir to the commit tree !)

Wrote a blog too if you wanna learn a bit about git internals : [check here](https://www.skshmgpt.tech/blog/git-internals)
